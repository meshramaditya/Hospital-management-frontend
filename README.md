# Hospital Management UI

Frontend for the MedCare hospital management system, built with Next.js, Tailwind CSS, and Radix UI components.

## Getting started

1. Install dependencies: `pnpm install` (or `npm install`/`yarn install`).
2. Run the development server: `pnpm dev`.
3. Open the app at http://localhost:3000.

## Notes

- Update environment variables (if any) before deploying.
- The UI includes dashboards, patient records, appointments, billing, and reporting screens.
